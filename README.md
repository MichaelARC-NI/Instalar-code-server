**Una aplicación web moderna, interactiva y de diseño *Dark Mode* para gestionar, instalar y respaldar Visual Studio Code-Server en dispositivos Android utilizando Termux.**

---

## 📖 Acerca del Proyecto

Este repositorio contiene una **Guía Interactiva Avanzada** diseñada específicamente para desarrolladores, estudiantes o entusiastas que desean convertir su teléfono o tablet Android en una estación de trabajo completa ejecutando **Visual Studio Code** nativamente a través de Termux.

El proyecto no es solo un documento estático; es una interfaz web de una sola página (SPA) que presenta una lista de comandos esenciales, con un sistema de copiado al portapapeles con un solo toque (One-Click Copy), diseñado para facilitar el proceso de instalación y configuración directamente desde el teléfono sin tener que escribir comandos largos manualmente.

### ✨ Características Principales

*   **Diseño UI/UX Optimizado:** Interfaz moderna estilo "Terminal/Dark Mode" utilizando Tailwind CSS, amigable para la vista y perfecta para entornos de desarrollo.
*   **Copiar con un Clic:** Botones interactivos en cada tarjeta de comando que copian el código directamente al portapapeles del dispositivo, con feedback visual (Toast Notifications) para confirmar la acción.
*   **Contenido Completo:** Cubre desde la instalación del repositorio TUR hasta la configuración de red y copias de seguridad profundas.
*   **Totalmente Responsivo:** Diseñado pensando en pantallas móviles (Mobile-First), pero se adapta perfectamente a tablets y navegadores de escritorio.
*   **Sin Dependencias Complejas:** Construido con HTML5, Tailwind CSS (vía CDN) y JavaScript puro (Vanilla JS). Listo para usar sin necesidad de compiladores (Node.js/npm no requeridos).

---

## 🛠️ Tecnologías Utilizadas

*   **Estructura:** HTML5 Semántico.
*   **Estilos:** [Tailwind CSS](https://tailwindcss.com/) (Ejecutado vía CDN para máxima portabilidad).
*   **Tipografía:** Google Fonts (`Inter` para lectura clara, `JetBrains Mono` para los bloques de código).
*   **Lógica:** Vanilla JavaScript (ES6+).
*   **Iconos:** SVG puros integrados para mantener la aplicación liviana.
