Entorno IDE Móvil Completo

VS Code en Android con Termux

Transforma tu dispositivo móvil o tablet en un entorno de desarrollo web profesional accesible localmente o desde cualquier equipo dentro de tu red Wi-Fi.

Tiempo de setup: ~10 min
Paquete: code-server (TUR)
Sin requerir Root
1

Requisitos Previos

1. Termux Actualizado

Debe estar instalado obligatoriamente desde F-Droid o GitHub. No uses la versión de Play Store (está obsoleta).

2. Conexión Wi-Fi

Necesitas una conexión a internet activa para descargar paquetes y acceso a la red local Wi-Fi compartida.

3. Misma Red

Ambos dispositivos (el teléfono Android y la PC/Tablet cliente) deben estar conectados en el mismo router Wi-Fi.

2

Guía de Instalación Paso a Paso

Marca los pasos completados

Asegúrate de que los repositorios de paquetes y dependencias básicas estén en su versión más reciente.

Terminal 
pkg update && pkg upgrade -y

Concede acceso a Termux para leer y escribir archivos en la memoria interna de tu dispositivo Android. 

termux-setup-storage
Acepta el mensaje emergente de permisos en la pantalla de tu móvil.

Evita que Android cierre o detenga el proceso del servidor cuando la pantalla se apague. 

termux-wake-lock

Añade el Termux User Repository para obtener compilaciones optimizadas de code-server. 

pkg install tur-repo -y

Instala el paquete principal de VS Code adaptado para ejecutarse en entornos móviles. 

pkg install code-server -y

Ejecuta el servidor una primera vez para que genere sus archivos de configuración iniciales. 

code-server

💡 Una vez veas que el servidor ha iniciado y muestre líneas de log, presiona Ctrl + C para detenerlo.

3

Configuración para Acceso en Red Wi-Fi

Por defecto, code-server solo escucha localmente en 127.0.0.1. Para poder abrir el editor desde una tablet o PC en tu red Wi-Fi, debemos indicarle que escuche en 0.0.0.0.
1. Modificar IP de escucha (Comando automático):
sed -i 's/127.0.0.1:8080/0.0.0.0:8080/g' ~/.config/code-server/config.yaml
2. Ver tu contraseña generada:
cat ~/.config/code-server/config.yaml

Copia la clave alfanumérica que aparece al lado del parámetro password:.

3. Obtener tu dirección IP local:
ifconfig

Busca el apartado wlan0 e identifica la dirección IP junto a inet (ej. 192.168.1.8).

4. Iniciar el servidor:
code-server
Herramienta Interactiva

Generador de Enlace de Conexión

Escribe la IP de tu dispositivo Android obtenida con ifconfig para calcular tu dirección exacta de acceso web.

Tu URL para ingresar en el navegador:
http://192.168.1.8:8080

Cómo Conectarse desde otro Dispositivo

1

Red Wi-Fi

Conecta tu PC o Tablet al mismo punto de acceso Wi-Fi que el teléfono.

2

Navegador Web

Abre Chrome, Edge, Firefox o Safari en el equipo secundario.

3

Ingresar Dirección

Escribe en la barra: http://IP:8080 (Usa siempre http).

4

Autenticación

Pega la contraseña obtenida de tu archivo config.yaml.

Solución de Errores Frecuentes

Error 1: ENOENT: process.cwd failed with error...

Causa: Termux perdió la ruta de la carpeta actual (por ejemplo si borraste una subcarpeta en la que estabas parado).

Solución: Vuelve al directorio principal de tu usuario en Termux ejecutando:

cd ~
Error 2: error listen EADDRINUSE: address already in use...

Causa: El puerto 8080 ya está ocupado por un proceso previo colgado en segundo plano.

Solución A: Finalizar procesos Node.js

pkill -f node

Solución B: Forzar el cierre del puerto 8080

fuser -k 8080/tcp
Error 3: El servidor se apaga al bloquear la pantalla

Causa: El optimizador de batería de Android destruye el proceso de Termux en segundo plano.

Solución:

  1. Ejecuta termux-wake-lock en la terminal.
  2. En Ajustes de tu móvil → Aplicaciones → Termux → Batería: Desactiva la optimización de batería y habilita el inicio automático.
6

Respaldo y Restauración

Crear Copia de Seguridad Completa

Guarda configuraciones, extensiones e historial en un archivo tar.gz en la SD Card:

termux-setup-storage && cd /data/data/com.termux/files && tar -zcvf /sdcard/termux-backup.tar.gz usr home
Restaurar Copia de Seguridad

Recupera todo tu entorno previamente respaldado:

termux-setup-storage && cd /data/data/com.termux/files && tar -zxvf /sdcard/termux-backup.tar.gz --recursive-unlink --preserve-permissions
7

Desinstalación y Limpieza

Desinstalar paquete: 
pkg uninstall code-server -y
Borrar archivos de datos y extensiones: 
rm -rf ~/.config/code-server ~/.local/share/code-server
